## 关于本书

《设计事件驱动系统》（*Designing Event-Driven Systems*）由 Confluent 的技术专家 Ben Stopford 撰写，以 Apache Kafka 为主要工具，讲述如何用事件和流处理来构建软件系统——从单个应用中的细粒度服务，到横跨整个公司的数据与服务架构。

本书的核心观点是：**流处理不只是请求-响应（REST/RPC）的另一种实现方式，而是一次思维方式的转变**——把业务看作不断演进的数据流，把服务看作将这些数据流转换为新数据流的函数。作者沿着这条主线，探讨了以下几个问题：

- 事件如何同时承担“通知”与“数据复制”两种角色，使服务之间松耦合又可插拔；
- 事件溯源（Event Sourcing）、CQRS 与有状态流处理如何让系统更易扩展、更易恢复；
- 为什么要把事件流作为公司级的共享事实来源，并让每个服务只保留自己需要的“瘦数据”；
- 在最终一致性的世界里，如何处理一致性、并发、事务（Kafka 的“精确一次”）以及模式的演进；
- 如何用 Kafka Streams 与 KSQL 构建一个完整的流处理服务生态。

全书共五个部分、十五章，篇幅精炼，兼顾概念与实践：前三部分偏重思想与架构，后两部分涉及具体机制与少量代码。书中的示例代码可在英文原书所附的 GitHub 项目中找到。

**适合的读者**：后端与架构工程师、正在评估或使用 Kafka 的团队，以及希望理解事件驱动架构与微服务数据共享问题的技术负责人。

## 关于翻译

本译本由 **choongth** 完成，旨在为中文读者提供忠实原著、表达自然的阅读体验。翻译遵循以下原则：

1. **忠实原意**：以英文原版为准，不增删观点；个别原文中的笔误（如 *Command Query Response Segregation*）按正确术语处理。
2. **术语统一**：全书同一概念使用同一译法，并在首次出现时附英文原文。常用术语见下表。
3. **人名与产品名保留原文**：如 Pat Helland、Martin Fowler、Kafka Streams、KSQL，不做音译。
4. **代码与链接不翻译**：代码块、标识符、主题名与 URL 保持原样，仅翻译代码中的注释。
5. **图表沿用原编号**：图、表的编号及插图与原书一致，图注已译为中文。
6. **交叉引用中的页码为英文原书页码**：如“第 14 章第 135 页”指英文原书的页码，章节名则与本译本的标题一致，便于查找。
7. **使用“你”称呼读者**：保持原书平实、对话式的语气。

如发现翻译错漏，欢迎提交 Issue 或 Pull Request。
